# 💻Proyectos Programacion
**Centro de guardado para proyectos**  
***Pasos para realizar cambios de manera correcta: (o eso creo)***  
*1️⃣- descargar ya sea github desktop o git. (más comodo github)  
2️⃣- clonar el repositorio (el cual es este, intentar guardarlo en algun lugar facil de acceder.)  
3️⃣- tras clonar, en github desk, inicialicen el IDE (Visual Studio) o el que vayan a utilizar, ahi estara la opcion.  
4️⃣- programar.*

*Al terminar de programar o querer hacer un cambio para que este no se pierda, en github desktop saldran que cambios se hicieron y simplemente darle a commit y luego a push.*

*Ya al volver a querer programar, delen "fetch origin" y luego "pull origin" para que se actualice el repositorio y no se pierdan los cambios de otros.*

>*En caso de querer usar git, ya son pasos más complejos de explicar, asi que veanse un videito.*
